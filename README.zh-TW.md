## 為什麼這不是人格複製器

叫模型去「當」某個人，你會拿到它本來就最拿手的東西：**聲音**。節奏、口頭禪、句子的形狀。你拿不到的是他的判斷力，因為判斷力藏在他輸出裡沒有人會剪成片段的那些地方：被追問的那一句、他拒掉的那個案子、一樁死掉的案子的覆盤。

所以人格式的 prompt 產出的顧問會**聽起來很對，但判斷得很通用**。那是最糟的失敗模式，因為那個聲音有說服力到讓你停止查核。

這支工具走反方向。它抽取的是決策規則，並且拒絕冒名，這樣一個答不出來的問題就會**讀起來像答不出來**，而不是被一種你熟悉的語氣抹平。

兩個後果，而這兩個就是整個設計：

1. **每一條歸給本人的宣稱都要指名來源並附上引文**，而且引文會拿去跟硬碟上的來源檔逐字核對。不是「他大概講過類似的話」，要那一段原文，否則這條宣稱不准交付。

2. **這支 skill 是拿「通用模型會答錯的題目」來計分的。** 題目是本人公開答過、但抽取階段從沒看過的，並且依一個**記錄下來的基線**分成兩池：同一個問題，在完全沒有載入任何重建的情況下的答案。

   任何實務工作者公開講出來的東西，大部分都是共識。而一份重建無論有沒有真的學到東西，都會把那些題目答對。放在同一池計分，「該算的十題對五題」加上「四十題共識題」會讀成 90%。所以共識池只報數、永不計入閘門，閘門讀的是**分歧池**：那些預設答案會答錯的題目，只有判斷力真的遷移過去才可能答對。門檻預設 80%，而那就是**基線之上的增益**，直接量出來而不是相減。

   還有一個誠實的後果，閘門會直接講出來而不是藏起來：**一個公開立場全是共識的對象，本質上無法有意義地重建。**

## 為什麼人比書難

把一本書蒸餾出來，大部分是搬運。作者已經替你做完知識工程了：框架有名字、章節有順序、案例配對到它們支撐的主張。

一個實務工作者的輸出沒有這些鷹架。它散落在好幾年和好幾種格式裡、重複、而且自我矛盾。他 2021 年持有的立場，可能是他後來反駁過的。而且它的權重是反的：公開素材大多是行銷用的，所以它帶著結論、藏起推理。

這決定了抽取要怎麼做。**來源不是等值的**：

| 權重 | 素材 |
|---|---|
| 高 | 被追問的訪談、公開反駁、覆盤、他拒掉的案子、對敵意提問的回答 |
| 低 | 主張文、宣傳文、金句、課程大綱 |

一份全是 keynote 跟懶人包的語料，生不出一條可用的決策規則，而 holdout 閘門會直接講出來，不會產一個聽起來很篤定的空殼。

## 它產出什麼

```
reconstructions/<slug>/
├── SKILL.md              決策規則，每條宣稱都帶來源錨點
├── decision-table.md     情境、他會先問什麼、判準、他會拒絕什麼
├── refusals.md           他在什麼條件下說不
├── contradictions.md     他哪裡自我矛盾，以及什麼條件能同時成立
├── sources.json          每一筆來源：授權級、日期、取得來歷
└── holdout-report.md     對齊率、分歧處、以及什麼仍然未知
```

`refusals.md` 往往是最有用的一份。任何人都能改寫一個實務工作者的正面主張，但**幾乎沒有人猜得到他在什麼條件下會拒絕**。那一塊才是行為像指紋的部分。

`contradictions.md` 把矛盾當成**發現**，不是問題。一個人 2021 年主張 A、2024 年主張相反的 B，很少是立場反轉：通常是某個**沒講出來的條件**變了，而把那個條件挖出來是整份重建裡最值錢的東西，因為那是他自己從來沒有明確表述過的判準。所以每一筆都必須回答「什麼條件能讓兩邊同時成立」，而找不出條件的那一筆就保持未解並標記出來。挑新的那個然後往前走，等於把發現丟掉。

它順便也讓一個顧問不會去引用它的對象已經公開放棄的觀點，而那是最快讓這種顧問失去可信度的方式。

## 來源授權分級

**逐份文件標，不是逐個專案標。**

| 級 | 素材 | 處理 |
|------|----------|-----------|
| **T0** | 本人提供的私域材料 | 需要一份指名它的授權紀錄 |
| **T1** | 公開且可自由引用 | 引用並標註 |
| **T2** | 公開但受著作權保護 | 只做短引文並標註出處 |
| **T3** | 付費牆內、外洩、從封閉社群抓來的 | **永不進入管線** |

T3 是一個**類別**，不是一個門檻。沒有任何授權紀錄、沒有任何產出流向能解鎖它。

## 影片，以及逐字稿到底是什麼

對很多對象來說，公開素材大部分是影片，所以蒐集必須處理字幕。其中有兩件事是**量出來的**而不是假設的，而且兩件都是拿一份真實的、人工撰寫的演講逐字稿（427 個 cue）跑出來才發現的。

**字幕是按顯示時間切的，不是按句子切的。** 在那份逐字稿裡，只有 59% 的 cue 結束在句末標點上，所以**每五條跨 cue 邊界的引文就有兩條會在 `G2-anchor` 掛掉**，而原因跟誤引完全無關：那條引文跨過了一個儲存方式自己造出來的邊界。所以 cue 會在存檔前先接合。

**逐字稿裡有別人的話。** 同一份逐字稿把 `(Audience) Good.` 直接存在內文裡，就在講者自己第一句話之後兩個 cue。不加區分地存起來，別人的話就變得可以被當成本人的話引用，而 `G2-anchor` 會**正確地**讓那條引文通過，因為那些字真的在來源裡。那是**儲存方式製造出來的張冠李戴**。

所以說話者的發言段落會被偵測並標記，而且標記是**往未知那邊失敗**的。偵測本質上是啟發式的，不可能不是：中文和日文沒有大小寫，而「我覺得：」的形狀跟一個說話者標籤一模一樣。一段發言只有在標籤對得上本人時才算本人的，只有在標籤直接寫明時才算別人的，其餘一律是未知，列出來給人處理。往任何一邊猜都是輸：猜「本人」，別人的話變成可以當他的話引用；猜「別人」，本人自己的話被丟掉。

**非本人的發言會保留，因為它們是語境而不是污染。** 「不一定。」這句話在沒有前面那個問句的情況下什麼都沒說，而且**本人被追問的素材是資訊量最高的素材**，所以每一段本人的發言都會記錄是什麼把它問出來的。

### 可錨定性是量出來的，不是信任來的

捷徑是去讀 YouTube 的 `trackKind`，它會把一條字幕軌標成 `ASR` 或 `standard`，然後把 `ASR` 當成比較弱的。**不要這樣做。** 修改一條自動產生的字幕軌之後它會不會被重新分類，我們查不到任何文件寫明，所以那個標籤可能對一條被人逐行修過的字幕說「自動」。它會被記錄下來，但它不決定任何事。

改成量**存下來的文字本身**：句末標點、以及句首大寫。在兩種語言、約 19 萬字的真實人工撰寫文字上，密度落在每一百字 1.02 到 1.85 個標點之間，而同樣這些文字把標點去掉之後量到的是精確的 0.00，所以門檻坐落在一個沒有東西會落進去的間隙裡。

**要精確講清楚這買到了什麼。** 它建立的是**可錨定性**：有句界的文字支撐得起引文核對，沒標點的流水句撐不起，因為沒有任何東西可以拿來當引用的邊界。它**不**建立「有人審過」，因為現在的語音辨識會自己加標點。把 `anchorable` 讀成「有人檢查過這個」，就讀出了超過這裡實際有的東西。

## 產出流向

**只有一個軸，因為只有一個問題需要開關：這份結果要去哪裡。**

| | `PRIVATE` 自用 | `PUBLISHED` 對外 |
|---|---|---|
| 來源分級閘門 | 執行 | 執行 |
| 來源錨點閘門 | 執行 | 執行 |
| holdout 閘門 | 執行 | 執行 |
| 揭露段 | 不要求 | **要求** |
| 冒名語句 | 警告 | **擋下** |

拿某個人的公開演講做一個顧問、給自己用，是很平常的事，這支工具不會為這件事對你說教。來源與品質閘門照樣跑，而且**不是為了保護那個對象**：一個憑空發明一條規則、然後講得很篤定的顧問，受害的是**你**。

**揭露只在別人會讀到產出時才適用**，因為那才是第三人可能被誤導的時刻。

## 它不會做的事

* 聲音複製，或任何形式的本人聲音再現
* 描繪本人的圖片、影片或虛擬形象
* 以第一人稱呈現、彷彿本人在說話的對話
* 任何暗示本人撰寫、審閱或認可這份產出的宣稱

**這些在任何流向下都拒絕。** 2024 到 2026 這一波 digital replica 立法（田納西州的 ELVIS Act、華盛頓州 SB 5886、加州 SB 1111、以及還在審的聯邦 NO FAKES Act）打的是**聲音與視覺肖像**。這支工具產出的是文字，而且留在那條線的這一側。

## 能力邊界

明白寫出來，避免這支工具被讀成提供了它做不到的事：

* **無法**驗證一份授權紀錄是真的。它只檢查結構。
* **無法**確認一筆來源是真實的、歸屬正確的、或者是現行的。
* **無法**判斷任何用途在任何司法管轄區是否合法。**這不是法律意見。**
* **無法**重建來源從未記錄過的判斷力。語料稀薄就產出稀薄的結果，並且照實回報它稀薄。
* **無法**偵測對象在建置完成之後撤回了授權。

## 安裝與使用

```bash
pip install .
```

五個子指令。每一個都只是包住一個**已經存在、已經測過**的函式，所以命令列只多
了參數解析與退出碼，別的沒有：一支自己帶判斷的 CLI 是第二套實作，而兩套一定
會分岔。

```bash
# 這個網址可以抓嗎？由 robots.txt 決定，不由別的決定。
persona-to-skill fetch https://example.com/post/1 --robots robots.txt

# 把符合匯入契約形狀的記錄寫成語料目錄。
persona-to-skill import export.json \
    --subject "某位實務者" --tier T2 --corpus corpus/

# 跑完一個 bundle 的每一道閘門，不打包。這一個是給 CI 用的形狀。
persona-to-skill gates bundle.json --corpus corpus/

# 先過閘門，每一道都過才寫 zip。
persona-to-skill package bundle.json --corpus corpus/ --out dist/

# 文件的標點閘門。
persona-to-skill punct docs/
```

**退出碼就是它之所以是一支指令的全部理由。** 0 代表閘門過了，非零代表沒過。
任何印出判定卻 exit 0 的東西，都是一道放不進 CI job 的閘門，而那等於沒有閘門。
不給子指令直接跑 `persona-to-skill` 也是非零：一支什麼都沒做卻成功的指令，
是同一個失敗的縮小版。

321 個測試與 11 道 CI 檢查全程綠的，因為沒有一個**跑過裝起來的那支指令**。
測試 import 這個套件；入口點是由一支 console script 解析的，而那支腳本只在安裝
之後才存在。

這是第四種「看起來是閘門其實不是」，而且是最純的那一種。另外三種是錯的、過期
的、沒測的，每一種至少還有東西可以檢查。這一種是**宣告了但不存在**：它在打包
後設資料裡讀起來像一個功能，而它解析到的是什麼都沒有。

現在有兩樣東西壓著它。`tests/test_entry_points.py` 解析 `[project.scripts]`，

新的守衛是綠的，而每一次 `fetch` 都以 traceback 結束。所以才有
`tests/test_cli.py`，它**呼叫** `main(argv)` 並斷言退出碼，而不是 import 完
就停。

## 閘門

**五道，每一道都配有負向測試：餵一份故意弄壞的輸入，它必須紅燈。** 一道不會失敗的閘門比沒有閘門更糟，因為它給出假的安全感。

| 閘門 | 擋在哪裡 |
|------|-----------|
| `G1-consent` | 出現 T3；T0 沒有授權紀錄；來源未分級或讀不到 |
| `G2-anchor` | 引文不在它聲稱的來源裡；數字在來源裡找不到；宣稱沒有來源 |
| `G3-disclosure` | 對外時出現冒名；揭露段不完整 |
| `G4-holdout` | 分歧池對齊率低於 80%；分歧題少於 5 題；基線缺失；超過 30% 未觀測 |
| `G5-interrogation` | Memo 欄位沒被回答；標為事實的宣稱沒有來源或帶避險詞；決定性數字還未知卻給出承諾性裁決；信心水位與未結的證據缺口互相矛盾 |

每一道閘門都**獨立重算**、在它依賴的輸入缺席時**fail closed**、而且讀的是**正在交付的那份產出**而不是寫死的範例。

`G5-interrogation` 存在的理由是：一場推演裡會出錯的東西都**藏在流暢的文字裡**：沒有來源卻寫得像既定事實的宣稱、悄悄壓在一個沒人驗證過的假設上的建議、在該說「我不知道」的地方站著一個避險詞。產出越漂亮，越需要這一關。它的規則裡有兩條承擔了大部分重量。**當決定這件事的那個數字還未知時，承諾性的裁決不可用**，因為那時候缺的是一個數字而不是一個意見。而**一個宣稱出來的信心水位必須與未結的證據缺口雙向自洽**：高信心配上一個壓在決策上的缺口是不自洽的，低信心配上什麼都不缺也是。

`G4-holdout` 把**未知當成一等狀態**。一個沒有記錄到觀測的項目既不算通過也不算失敗：它離開分母，並且單獨回報。未知比例過高會讓閘門紅燈，而且歸咎於**題庫**，因為缺陷在那裡。（`bool` 在 Python 裡是 `int` 的子類，所以一個 JSON 的 `true` 會通過一個天真的整數檢查、然後被當成 1 加總，所以這個模組拒絕發明一個沒有人記錄過的分數。）
